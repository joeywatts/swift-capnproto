# capnp_test provenance

The directory `capnp_test` is an unmodified copy of `kaos/capnp_test` commit
`9aad1331857d2b02158cffdba4d664f71f7f81de`. Its Apache-2.0 license is preserved
as `capnp_test/LICENSE`. Generated `expect` data and the harness's `actual.*`
scratch files are deliberately not committed.

The sibling `Adapters` directory and `Scripts/verify-capnp-test.sh` are local
verification support and are not part of the vendored suite.
